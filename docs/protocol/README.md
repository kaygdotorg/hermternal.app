# Protocol planning

Hermternal v0.0.1 will target the Hermes Dashboard protocol. It will not target the separate Hermes API server contract.

The supported surface will include the required authentication routes, WebSocket ticket route, chat WebSocket, session operations, prompt operations, and chat events. Each release must pin a reviewed Hermes revision and test against redacted fixtures.

Dashboard protocol names found only in source are not assumed to be stable. Compatibility changes require review before client code changes.
