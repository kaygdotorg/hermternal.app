# Product scope

Hermternal v0.0.1 is the first live chat client for web, iOS, and iPadOS.

The release will focus on authentication, connection, session creation and restoration, prompt submission, streaming responses, tool states, approvals, clarification, interruption, reconnect, and clear loading, empty, success, and failure states.

The release will not include dashboard administration, PTY/TUI access, direct SSH, Hermes terminal backend selection, direct `~/.hermes` access, Android, Windows, or production telemetry. macOS follows after the Apple interaction model is proven.

Detailed acceptance criteria will be tracked as atomic implementation issues.
